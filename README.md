# 🐾 PetShop - Sistema de Gerenciamento de Pets

## 📖 Sobre o Projeto

O PetShop é um sistema desenvolvido em Python com o objetivo de auxiliar no gerenciamento de animais cadastrados em um pet shop.

O sistema permite cadastrar, consultar, listar e remover animais, facilitando o controle dos atendimentos realizados. O projeto foi criado para praticar conceitos de programação, banco de dados e organização de software.

---

## 🚀 Funcionalidades

* Cadastro de animais
* Listagem de todos os animais cadastrados
* Pesquisa de animais por nome
* Atualização de informações dos animais
* Exclusão de animais após o atendimento ou consulta
* Armazenamento dos dados em banco de dados

---

## 📝 Dados do Animal

Cada animal possui as seguintes informações:

* Nome
* Espécie
* Raça
* Idade
* Nome do responsável
* Telefone para contato
